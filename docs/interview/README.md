# Interview prep pack — Azure DevOps Consultant

Use this pack when an interview is **days away** and there is no time to deploy the whole lab. It turns the platform in this repository into talking points.

| File | Use it for |
|---|---|
| [01-pitch.md](01-pitch.md) | The 30-second and 2-minute story of this platform. Rehearse it **out loud**. |
| [02-technical-answers.md](02-technical-answers.md) | ~40 likely technical questions with short model answers (Terraform, pipelines, AKS, networking, security, observability). |
| [03-consultant-scenarios.md](03-consultant-scenarios.md) | Consulting questions: discovery, trade-offs, difficult stakeholders, migration, cost. STAR templates for your own stories. |
| [04-interview-english.md](04-interview-english.md) | Phrases to structure answers, buy time, disagree politely; false friends for Portuguese speakers; pronunciation traps. |

## 3-day plan (≈ 3 h/day)

| Day | Morning (1.5 h) | Evening (1.5 h) |
|---|---|---|
| 1 | Read [HOW-IT-WORKS](../HOW-IT-WORKS.md) sections 1–7. Rehearse the 30-second pitch until it is natural. | Technical answers: Terraform + pipelines blocks. Answer each **out loud** before reading the model answer. |
| 2 | Technical answers: AKS, networking, identity, security. | Consultant scenarios: write 4 STAR stories from your real projects. Record yourself telling one (phone audio). |
| 3 | Technical answers: observability + "design a platform" question. Rehearse the 2-minute pitch with the diagram. | Interview English: phrase bank + false friends. Mock interview: pick 10 random questions, answer in English, time yourself (≤ 2 min each). |

**Night before:** do not study new content. Re-read the pitch, your STAR stories, and the "buying time" phrases.

## How to answer any technical question (the consultant shape)

1. **Clarify** — "Just to make sure I understand: are we talking about a greenfield setup or an existing environment?"
2. **Answer the core in one sentence.**
3. **Explain the why** — the trade-off you are making.
4. **Give a real example** — "In my last project…" or "In my lab platform…".
5. **Mention the risk or the alternative** — this is what makes you sound senior.

Interviewers for consulting roles score *communication* as much as knowledge. A clear, structured "I don't know X, but here is how I would find out" beats a confused correct answer.
