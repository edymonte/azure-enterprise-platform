# Phase 14 — Portfolio and mock interview (2 h)

## 🎯 Goal

Turn the lab into something a hiring manager can evaluate in 2 minutes, and rehearse explaining it.

## 🛠️ Steps

1. **README screenshot set** (`docs/images/`, add the folder): Argo CD app tree, Grafana dashboard, Datadog APM service page, Front Door custom domains, Policy compliance page. Reference them in the README.
2. **Architecture diagram**: export the mermaid diagram from HOW-IT-WORKS §2 (or draw it in draw.io) to `docs/images/architecture.png`.
3. **ADRs**: re-read `docs/decisions/`; add one ADR of your own about a decision you changed during the lab.
4. **Short demo video (3 min, English)**: PR → pipeline → Argo CD sync → chaos → alert → revert. Record with OBS or the Xbox Game Bar (`Win + G`).
5. **LinkedIn post (English)** — structure:
   - Hook: one line with the problem ("How do you run AKS with zero secrets?").
   - 3–5 bullets with decisions and trade-offs (not a list of services).
   - Link to the repo and video.
6. **Mock interview**: run [docs/interview/](../interview/README.md) end to end, timing each answer.

## ✅ Checkpoint

- [ ] Repository README tells the story with images.
- [ ] You can give the 2-minute pitch without notes.
- [ ] You can answer every 🎤 question from phases 01–12 in English.
